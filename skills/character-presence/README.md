# Character Presence｜人物生成与一致性技能

面向 GPT Image 的中文人物生成、局部改图、表情、人设表达与多视图参考技能。

## 能做什么

- 生成人物：把角色设定转成可见的外貌、表情、动作和场景。
- 局部改图：明确修改项，保留未要求改变的脸、服装、裤子、鞋及背景。
- 表情与人设：表现轻慢、讨好、克制愤怒等状态，保持同一角色身份。
- 多视图与视频参考：维护角色基准、服装版本、左右细节与镜头状态。

安装和发现机制取决于宿主应用；仅下载或打开 README 不代表已经安装。在支持显式调用且技能已加载的环境中，可以使用 `$character-presence`。

示例：

> 使用 $character-presence，根据附件人物生成正面、左侧面和背面参考图，保持脸、发型、服装和鞋一致。

> 使用 $character-presence，只去掉胡须与黑色内搭，保留原睡裤、黑鞋、睡袍、背景和所有视图布局。

> 使用 $character-presence，为这个虚构的势利角色写两张态度对照提示词：面对想讨好的人，以及面对不愿认真接待的人。不要换脸，不要换装，只给提示词。

## 使用条件与边界

这是技能指令包，不包含模型、API 密钥或独立生图程序。写提示词可直接使用；生成和编辑图片需要宿主提供相应图像工具及访问权限。不会因为加载技能就自动生图。

面相与戏曲意象仅用于虚构角色造型，不用于从真人外貌判断人格或善恶。人物一致性需要检查实际图片；视频仍需逐镜头验证，不能保证绝不穿帮。
