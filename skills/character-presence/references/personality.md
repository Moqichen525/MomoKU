# 人设与可见表现

用于已指定的虚构人物、表演角色或人物造型设计。借鉴传统相貌描写的表达意图，但使用可见、可控制、能保持角色一致性的设计方法。这里的对应关系是创作选项，不是真人性格判定表。

## 从人设到画面

根据用户已给的信息形成一个简短工作描述，不要求用户填写表格：

**角色想要什么 → 对谁采取什么态度 → 当下情绪 → 画面中的表情、动作与关系 → 哪些身份和服装必须保留。**

例如：“想攀附有权者 → 对主办人主动讨好，对办事者敷衍 → 表面热情、注意力有选择 → 身体迎向主办人，却把办事者递来的材料晾在一侧”。这是剧情设定带来的表现，不是从角色鼻子或眼睛推断出来的人品。

没有对手或情境的纯头像可以表现疏离、警觉、倨傲等印象，但很难唯一指向势利、背叛或贪财等复杂动机。不要用越来越多五官形容词掩盖信息不足。

## 面部、造型和表演如何配合

- **固定形象**：新角色可按美术方向选择柔和或利落的轮廓、眉形修整方式、发型与妆容。它们控制视觉风格和辨识度，不自动定义善恶；同一种外貌可以扮演善良或恶意的角色。
- **眼神和眉眼**：明确看谁、关注哪里，以及上眼睑、眉间的轻微变化；避免只写“奸诈的眼睛”。保持眼睛本身大小、虹膜颜色和五官位置不变。
- **嘴部与下颌**：轻抿唇、克制笑意、一侧嘴角轻抬、下颌紧张可用于某个瞬间；不是固定的性格标记。不靠歪嘴、牙齿异常或永久不对称制造反派感。
- **头颈与身体**：抬下巴、侧身避开、主动前倾、对某人让出空间等，说明角色怎样对待他人。动作有对象和动机，不能随意套用。
- **服装和道具**：用穿戴方式、整洁程度及如何使用道具补充人设；贵重物品、职业制服或贫穷衣着本身不代表善恶。已有图未授权换装、加饰品或加人物时不改这些内容。
- **照明与构图**：可以烘托场景，不能仅靠黑暗灯光就声称“势利”准确呈现。人物基准图优先让脸部结构清楚，戏剧照明放到剧情图中。

## 人设选项：依据具体场景组合

| 已知人设 | 可见表现的创作方向 | 容易误读的地方 |
| --- | --- | --- |
| 势利、趋炎附势 | 对有权者笑容展开、主动前倾；对另一对象视线避开、笑意收起、回应敷衍 | 只有冷脸更像疲惫或傲慢，需要对象关系支撑 |
| 表面和善、实际控制欲强 | 表情温和、手势却占住文件或决定他人位置；内外意图有轻微反差 | 只画“笑不达眼底”不能证明恶意，具体动作更清楚 |
| 自负、轻视对手 | 下巴略抬，听人说话时注意力偏开，嘴角有克制的轻蔑 | 不等于正在生气，也不必眯成一条缝 |
| 计算利益、谨慎盘算 | 视线关注已有合同或利益对象，动作短暂停顿，嘴部放松程度降低 | 沉思也可能同样呈现，需要给清楚的利益情境 |
| 凶狠、正面威胁 | 视线锁定对方，眉间与下颌紧绷，身体形成压迫性位置 | 与势利不同，不要把所有反派都画成咆哮或暴怒 |
| 温厚、愿意帮助 | 耐心关注求助对象，身体让出空间，手部动作开放而具体 | 不是圆脸、浓眉或某种体型天生善良 |
| 隐藏身份的反派 | 按剧情需要保持可信或亲切的表面，关键细节只在指定镜头泄露 | 不能同时要求“完全看不出”和“观众一眼认出恶意” |

选择满足当前镜头的少量线索，不把整行所有动作全部堆入提示词。新角色设计与现有图局部修改分别遵守允许变化范围。

## “势利眼”的提示词示例

### 现有角色头像，增加倨傲轻慢感

前提：用户已指定虚构角色势利，允许改表情、视线和头部微小姿态；不允许换脸或衣服。

> 以图 1 为同一人物基准，只调整表情与头部的轻微姿态，呈现他正在轻慢回应画外一位他不愿认真接待的人：下巴略抬，目光从对方脸侧移开，上眼睑略放低，唇角保留一点敷衍的笑意，整体克制，不作愤怒咆哮。保留原脸型、五官比例、眼睛大小、鼻形、年龄感、肤色、发型与既有标记。服装各层、裤子、鞋、配饰、背景、构图和照明保持原样，不添加人物、伤疤或新饰物。

交付时说明：此头像表达的是轻慢的一面；如果必须明确读出“见高捧、见低踩”，更适合下面的对照，而不是夸大五官。

### 同一张脸的态度对照

仅在用户要求表情组或同意用对照呈现时执行。保持身份、服装、光线和近景角度一致，分别生成两张，不把不同人物混入身份参考。

> A：以图 1 为人物基准，表现他面对希望讨好的有权者。视线专注于画外对方，笑容主动而略显用力，头部轻微前倾，嘴角和眉眼表达热切迎合；保持原五官、年龄、发型、衣着及场景。不要重塑鼻子、眼睛或下颌。

> B：沿用同一人物与服装基准，表现他面对自己不愿认真接待的人。笑意收起，下巴略抬，目光偏开，嘴唇轻抿，呈现敷衍和不耐烦；保持与 A 相同的面部结构、近景角度和照明，不换脸、不换装。

对照的解释写在随图文字中，不靠向脸上添加“坏人”“势利眼”标签完成表达。左右视图是角度差异，不是善恶版本；表情组才承担态度变化。

## 使用强度与连续性

- 用户希望“一眼看懂”：采用明确的情境关系和容易读出的表现，仍避免夸张丑化。原创场景可以安排对手或已有道具；原图编辑未授权时不要新增。
- 写实剧情默认克制：让线索足够可见，但不保证所有观众有相同理解。
- 隐蔽或反转角色：按剧情信息量安排，不因“反派”二字就给他所有镜头都加阴笑。
- 同一人物可讨好、轻慢、疲惫、真诚或失控；性格不是永远同一个表情。每张图记录情境状态，固定身份基准不变。
- 改图验收同时检查“像原来的人”和“表现了指定态度”；看不出人设时先改表情/动作/情境，不先缩眼睛、拉长鼻子或改脸。

## 资料与边界

核对日期：2026-10-21。

- [Marini 等的原始实验](https://link.springer.com/article/10.1007/s12144-022-03277-7) 检验面部可信印象如何影响人们对语句可信度的判断。它支持“脸部印象会影响观众”，不证明可以由面貌识别真实善恶、人格或谎言。
- [UC Berkeley Cal Performances 的戏曲相关教学资料](https://calperformances.org/learn/k-12/pdf/2007/Guangzhou0708.pdf) 介绍京剧脸谱等舞台约定。符号化造型可供创作借鉴，不能把脸谱颜色当成现实肤色与人品的对应关系，也不能把戏曲脸谱等同于面相学。

本文件的表演提示词是针对人物设计提出的创作方法，没有经观众盲测验证，不是面相科学或诊断规则。不要写“这种眼睛的人一定势利”“某种鼻子天生坏”。
